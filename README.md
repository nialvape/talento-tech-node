# Preentrega de NODE de talento-tech
La preentrega tiene dos requisitos principales, el primero es la configuracion inicial basica del proyecto y el segundo la logica de gestion de productos mediante argmentos en el comando "start".

Decidí esta vez agregar una tercera capa y es levantar el servidor con express que me servirá para continuar con el proyecto final. Para esta preentrega un cli.js se encarga de parsear los argumentos en requests validas y hacer los llamados al servidor previamente levantado.
